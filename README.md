What I Learned
Webpack: I found Webpack quite impressive because I didn't expect it to update the page automatically without manually refreshing it. It felt very reliable and active, like a car's cooling system operating continuously.
JavaScript: I became more familiar with JavaScript fundamentals such as function, const, objects, arrays, and event handling.
Modules: I learned how to split JavaScript into separate files and connect them using import and export.
Named and default exports/imports: I learned the difference between named exports/imports and default exports/imports.
Code organization: I learned why minimizing unnecessary duplication is important for maintaining and operating code properly.
Connecting files: I learned how different JavaScript files can work together as one application.
DOM manipulation: I became more familiar with creating elements, changing their content, adding them to the page, and responding to button clicks.
and how i learn is actually through pseudo-code.

My Learning Opinion

I don't think it is important to memorize every syntax or concept. I think it is more important to become familiar with them and understand what they are used for. With practice, the understanding becomes stronger and remembering things becomes more natural.
